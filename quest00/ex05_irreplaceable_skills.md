Lowest-Rated Skill: Conceptual Understanding (Knowing WHY, not just HOW)
Rating: 2/5

I chose Conceptual Understanding because I am still building my ability to fully understand why code works, not just how to write it. I sometimes understand the mechanics, but I want deeper clarity on the reasoning behind concepts like indexing, loops, and problem structure.

3 Specific Actions I Will Take This Week (Without AI):

Explain Concepts in Plain English
Three times this week, I will choose one programming concept (like indexing, loops, or functions) and explain it on paper in simple words without looking at notes or using AI. If I cannot explain it clearly, I will review it until I can.

Predict Output Before Running Code
Every time I write code, I will predict the output before running it. I will write down what I think will happen and why. Then I will run the code and compare the result to my prediction.

Rebuild Code From Memory
I will choose one program (like a palindrome checker) and rewrite it from memory after 24 hours without using AI or copying previous code. If I get stuck, I will think through the logic step by step instead of immediately searching for help.
